# 多人阶段实验矩阵（一次性原型）

先建矩阵，后分批运行。M=Node内存模型，F=独立临时JSON文件往返，S=既有双版源码探针，N=原生游戏/网络/大厅，C=受控生成任务。M/F/C不绑定游戏版本；S/N目标分别为public v0.107.1与public-beta v0.111.0，不能将同一模型跑两遍称双版支持。

|问题/批次|版本/人数|操作顺序|预期|证据/环境|
|---|---|---|---|---|
|1 同块/落点/连删/关联锁|M，3|甲拿A→乙丙争A→乙动关联B→甲取消；独立块争落点；重复建删|仅先接受者成功，取消保留关联|M操作日志；N尚待实现|
|2 同意与撤票|M，3及1|自动/检查切换取消；枚举最后票与撤票两个顺序；持有者断线|同选仅执行一次，断线先取消再判断，迟到编辑拒绝|M；N真实断线待验|
|3 阶段恢复|M/F，3|编辑持有→退出；已授权执行→退出；检查失败→退出；成功→退出；写半文件→异常恢复|清临时票，执行重跑无需投票，失败撤回保留，成功图保留，只读完整点|F临时目录；N原版保存大厅未运行|
|4 先古之民|M/F，3，恢复2|部分奖励→恢复；全员完成→恢复→共同继续|部分整体回退奖励，完成不重发；继续重收；名单与在局分离|F；N奖励副作用/原生Ancient断线适配待验|
|5 进入/计步|M/F，3|票店/店/事件→固定抽取索引→失败→恢复重试→确认→重复；同店新进入；事件连续战斗|按玩家票非去重；重试不重抽，成功一次扣步，内部战斗不扣|M/F；N单客户端失败待验|
|6 过场|C/F，3|授权→动画结束→字幕等待→保存→恢复→成功/失败/取消|等待不提前替换，失败原布局；恢复授权保留|受控任务替代生成器，不证明算法/原生动画；N待验|
|7 追猎检查点|M/F，3|1步进事件→内部战斗→全队完成→重试发放→受罚战斗→恢复→最终Boss胜利→恢复|本房安全；各一面具；开场效果标志/计数整体保留；末Boss不返还|M/F占位战斗状态，不证明原生战斗序列化；N待验|
|8 单人/版本差异|M，1；S双版|单人立即执行；重跑既有时序探针；复核消息/休息/退出/保存来源|单人同规则；public缺beta休息完成接口；普通退出不抓任意状态|M/S；真实消息注册/网络传输/大厅保存均未运行|

模型只检验规则可表达与给定接受序列，不证明真实网络会建立该序列。未决定最终集成端、协议或存储架构。普通拿放几何沿用已完成手动交互票的证据；此处块是符号，不重新实现几何。算法/逐敌/服务专项不在本原型实现。
