# 空箱开箱视觉验收（独立原型，未验收）

只回答空奖励时原生开箱动画、提示及继续是否可用。独立包强制所有宝箱为受罚输入，不实现额度、面具、多人状态或保存恢复。Agent只在Godot测试宿主运行，没有安装或启动游戏/Steam，没有读取真实存档。

## 用户安装和启动

用户自行选择匹配当前完整版本的 `dist/public-beta/AllMattersHuntingTreasureProbe/`（v0.111.0）或 `dist/public/AllMattersHuntingTreasureProbe/`（v0.107.1），安装其中同名DLL/JSON；完整RitsuLib0.6.7依赖由用户保留。输出根见[验收索引](../ACCEPTANCE-INDEX.md)。不要覆盖正式AllMatters。本包没有PCK、没有作者素材，实验后由用户禁用或移除。

1. 使用新开的试验跑局进入宝箱，先确认启动日志有 `[AllMattersHuntingTreasureProbe]`。记录完整版本、人数、语言、分辨率/窗口和输入设备。
2. 使用鼠标开箱，观察原生箱子开启动画、空箱文字/烟及淡出；金币和遗物均不增加；无需选择遗物，不停在空投票。
3. 确认“继续”能正常返回地图；再以键盘、手柄重复可执行的开箱/继续流程，记录焦点是否可见、空箱文字是否遮挡。
4. 如果新试验跑局恰有 N'loth's Hungry Face 或 Spoils Map，记录面具消耗、任务完成/移牌/地图标记消失且不发钱。不要改真实存档来造条件；这些行为已有自动证据，用户只补游戏中的显示结果。
5. 多人时只需记录真实各客户端的画面、空投票和继续结果；本包的单进程上下文不是最终联网设计。失败时保留所有客户端日志，不将同机1–4模型输入当多人验收。

## Agent已验证与未验证

`treasure-package-r2.log` 实际加载双版独立DLL，运行双版原生Collection/Tween；beta准确原场景Ready/OpenChest/Spine/空VFX/原生淡出/两等待任务与继续边界已运行，并组合全员Face消耗、本地Spoils任务/移牌/移标记/完成历史及全员异步非奖励计数。非本地任务等待自身客户端执行，不称网络通过。外围游戏/输入/地图、热键、peer hands和外部屏幕跟踪接缝被隔离；FTUE在调用前隔离，避免写进度。public没有匹配PCK，只有方法级真实运行，不宣称public完整屏幕通过。

本包只覆盖原生及奖励列表路径。第三方异步钩子直接 `RelicCmd.Obtain` 仍可能发遗物，未知调用方若要求实际入库也不能用空返回兼容；不要把此包当通用奖励禁止器。全局单开箱 `NormalCall` 输入只是实验，未选择集成架构。保存恢复、原生联网与完整FTUE不由本包批准。
