# 休息点最小实机实验（用户结果待回填）

仅验证休息点显示/执行边界。此独立包把每个原生休息房间作为“追猎已生效”的显式实验输入；不实现预算、面具、多人完成聚合或恢复，不适合正常跑局。

Agent运行 `./prototypes/hunting-boundaries/rest/Build.ps1 -Branch All` 生成 `dist/public/AllMattersHuntingRestProbe/` 和 `dist/public-beta/AllMattersHuntingRestProbe/`，只含独立DLL及JSON，无素材。需完整RitsuLib 0.6.7对应版本依赖（[官方发布](https://github.com/BAKAOLC/STS2-RitsuLib/releases)）。Agent不会安装或启动游戏。

1. 用户自行选择对应版本的包，在测试跑局中手动安装/启动；不要覆盖正式AllMatters目录，不使用珍惜的现有跑局。
2. 进入原生休息点：休息保持原图标与原说明；锻造及铲子等新增非休息选项保留图标/说明但灰显。以鼠标、键盘、手柄确认，禁止项不应执行或消耗选择次数。此包不通过替换选项模型或删除选项实现灰显。
3. 选择休息应触发原生治疗；有皇家枕头时保留加成，有迷你帐篷时保留原生额外次数，此时禁用项仍不能执行。多人修补需后续多人环境验收，自动实验已用受控远端选择输入测试，不证明原生联网。
4. 检查说明悬浮、焦点遍历、窄屏/宽屏，记录版本、分辨率、原生/额外选项、可读性、是否越过执行限制。public原生退出即完成，beta原生退出等待全部参与者；本包不改变版本时序。
5. 普通事件的休息/付费治疗应照常；包仅匹配RestSiteRoom。实验后由用户禁用/移除独立目录。

待用户实机结果，不预先标通过。此包的限制只对当前进程生效，不能用于验证完整保存/恢复。
