# 商店边界最小实机实验（结果待用户回填）

这是强制“追猎已生效商店”的独立输入，不实现预算、面具、房间完成聚合或恢复；每个MerchantRoom都会受限制。只在用户自行管理的测试跑局使用。Agent不安装、不启动游戏、不动存档。

运行`./prototypes/hunting-boundaries/shop/Build.ps1 -Branch All`生成`dist/public/AllMattersHuntingShopProbe/`及`dist/public-beta/AllMattersHuntingShopProbe/`，仅DLL+JSON。用户自行选择与游戏版本匹配的独立目录及完整[RitsuLib 0.6.7依赖](https://github.com/BAKAOLC/STS2-RitsuLib/releases)安装，不覆盖正式AllMatters目录。包不附带游戏资源。public原生PCK本机无备份，宿主没有验证public原版完整商店界面。

1. 用户手动启动游戏，在测试跑局进入商店并打开商品界面。卡牌、遗物、药水应隐藏；删牌保留原生Used动画外观且无费用，不伪造真实Used。
2. 鼠标点击原商品区域/删牌、键盘确认和手柄导航/确认均不能购买或删牌。金币、牌组及删牌使用次数不应变动。按返回后重开商店，限制应持续，原库存不应被重抽。
3. 返回按钮、商人对话和离开商店应正常；此包不触发面具或完成判定。检查常用分辨率、窄屏/宽屏下的遮挡和焦点，记录物理输入设备。
4. 原生商店之外的普通事件治疗/服务应正常。自动实验已运行Cleric付款治疗；实机有同类事件时可复核，不必为此反复刷图。
5. 记录游戏完整版本、分辨率、四类入口显示/执行结果、重开结果、金币/牌组前后及错误日志。跨店动态价格、Courier补货模型和真实库存/RNG未改由自动实验覆盖；本包不实现完整保存重访，不能用本次检查宣称恢复通过。
6. 实验后由用户禁用/移除此独立包。未收到结果前保持待验收。
