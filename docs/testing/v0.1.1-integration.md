开发目标为 public 0.107.1、public-beta 0.111.0，不宣称是最新发行版。自动化继续使用真实目标 DLL、既有 Godot 宿主和本机 beta 资源包／Spine 库；不等同完整 public 游戏环境。你好世界与 11 个 v0.1 事件继续包含在现有完整回归入口。
