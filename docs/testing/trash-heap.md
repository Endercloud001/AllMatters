## 用户人工验收

1. 退出游戏，备份现有模组。将对应目标的完整 `dist/public-beta/AllMatters/` 或 `dist/public/AllMatters/` 目录复制到游戏 `mods/AllMatters/`；完整 RitsuLib 0.6.7 variant-pack 独立安装在 `mods/STS2-RitsuLib/`，保留 compat、shared、assets.zip 等文件。由用户通过 Steam 启动对应版本；Agent 未安装、启动游戏或更改存档。
2. 在可丢弃测试局使用已有控制台 `event TRASH_HEAP`。中英文检查原图、原叙述及两个选项：随便拿点垃圾显示并增加 50 金币，永久获得一张保留候选；深入损失 8 生命并获得黑石护符、捕梦网或手钻之一。重复测试确认五张保留牌仍出现，移出的五卡两遗物不再出现。强制事件入口不证明自然准入。
3. 用故障机器人检查弹回/狂乱撕扯为罕见、堆栈普通；用铁甲战士检查双持/巩固罕见。通过正常奖励、商店与生成观察其可获得性、卡图和升级；巨口储蓄罐/发条靴应从普通遗物来源取得，原效果继续生效。控制台直接给物品不能代替正常池验收。
4. 战斗中可用 `card OUTMANEUVER`、`card DISTRACTION` 定位原生卡。抢占先机及升级版均显示奇巧，主动弃掉会自动打出并分别提供下回合 2/3 能量。声东击西两形态均 1 费且消耗；未升级生成普通状态技能，升级生成升级技能，当回合免费、下回合恢复正常费用；满手牌时遵守原生溢出。检查中英文普通显示、升级预览及已升级牌查看预览，绿色仅标出新增的“升级过的/Upgraded”。
5. 事件前保存后恢复再选；结算后保存恢复，检查无重抽、重复加钱/给卡/给遗物或扣血。双人时分别选两分支，确认金币、牌、遗物、损血、生成技能及下回合能量只归本人；回放核对相同结果。另复验你好世界升级牌效。

实机安装、自然池抽取、完整 public 资源、保存恢复、真实联机及回放均待用户执行。无界面测试替代现有宿主生命周期，不据此宣称这些项目已通过。
