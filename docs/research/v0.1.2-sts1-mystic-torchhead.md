# STS1 原生神秘术士与火炬头：只读复用调查

2026-11-03。目的：追踪原始 STS1 实现，补足仅阅读 ActsFromThePast 移植的证据缺口；不交付功能，不分发游戏代码/贴图。

## 来源与最小探针

一手输入为本机安装 `E:/SteamLibrary/steamapps/common/SlayTheSpire/desktop-1.0.jar`，非第三方反编译站。`E:/SteamLibrary/steamapps/appmanifest_646570.acf`显示 buildid `10180494`、StateFlags `4`；`CardCrawlGame.class`常量池只读检索得到`[V2.3.4] (12-18-2022)`及`2022-12-18`。该记录用于识别本次样本，不推断当前最新版本。

工具：`C:/Users/Endercloud/.jdks/ms-21.0.10/bin/javap.exe`与`jar.exe`。仅运行JDK检查器读取类文件，未运行游戏类、游戏进程、Steam或任何上游脚本；未写安装目录。完整游戏jar与资产没有复制到研究分支。

可复现命令（退出码均0，除下述已纠正类型查询）：

```powershell
$jarPath = 'E:/SteamLibrary/steamapps/common/SlayTheSpire/desktop-1.0.jar'
jar tf $jarPath
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.monsters.city.Healer
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.monsters.city.TorchHead
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.monsters.city.TheCollector
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.actions.common.SpawnMonsterAction
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.monsters.AbstractMonster
javap -classpath $jarPath -p -c com.megacrit.cardcrawl.actions.animations.AnimateSlowAttackAction
```

Python标准库`zipfile.ZipFile`以只读模式访问jar，`json.loads(z.read('localization/zhs/monsters.json'))`核对 `Healer.NAME=神秘术士`、`TorchHead.NAME=火炬头`；以只读JSON核动画skeleton及animations；常量池用`re.findall(rb'[\x20-\x7e]{5,}', z.read('com/megacrit/cardcrawl/core/CardCrawlGame.class'))`筛版本字符串。未加载Java游戏类。一次按`monsters.city.Collector`查询退出1（不存在），通过jar条目核准名称`TheCollector`后成功，不以相似名称替代。

证据定位采用“jar entry + 方法 + 字节码offset”，避免不同javap显示换行导致行号失真。以下结论都是字节码/资源元数据阅读等级，未编译STS2版本适配、更未实机验证。

## 原生行为与追猎方案逐项对比

## 与现有移植交叉核查

本地`.local/references/ActsFromThePast/ActsFromThePast/Acts/TheCity/Enemies/Mystic.cs`的GenerateMoveStateMachine/SelectNextMove/Attack/Heal/Buff，是C#移植而不是原生源码。它把治疗固定20×人数、增幅低进阶3/高4、攻击重复一律不能连、治疗阈值20×人数，已经和STS1上述低进阶行为不同，也和本方案固定循环/随机单目标不同。

同目录TorchHead.cs使用BaseLib.CustomMonsterModel、TACKLE自循环、伤7、Godot定时器发TorchHeadFireEffect和反射找fireslot。可作Godot接线候选，但没有证据证明它能在本项目两版本编译/正确清理/显示；不能因移植存在宣称本项目已支持。

参考目录没有独立.git或独立LICENSE可识别，父项目git HEAD不能冒充该参考来源revision。两份代码复制授权、Spine素材来源及再分发条件仍待核；不运行参考构建脚本。STS1原版代码/资产为专有内容，本机可读不等于许可复制到GPL项目或发布包；本轮仅记录入口和行为，不分发反编译内容或资产。用户自供贴图的许可也不能推及STS1骨骼/图集。
