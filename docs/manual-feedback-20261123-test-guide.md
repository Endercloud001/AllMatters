# 事件文案与碎块选中框实机验收

## 安装

退出游戏。按游戏分支选对应测试包，把解压得到的 `AllMatters/` 目录放入游戏的 `mods/`。保留独立安装的完整 RitsuLib 0.6.11 variant-pack。

| 游戏版本 | 测试包 |
| --- | --- |
| public-beta 0.113.1 | `AllMatters-public-beta.zip` |
| public 0.107.1 | `AllMatters-public.zip` |

## 修复后验证项

1. 打开增益研究者，确认「试一下 J.A.X.」里「牌组」前紧接「你的」。用两个初始遗物不同的角色打开「喝突变剂」，确认两者显示各自的遗物名，悬停可看见对应遗物和突变之力的描述。若原初始遗物已经失去，选项应锁定。
2. 打开面具强盗，将鼠标停在「开战」上，确认出现红面具的描述。
3. 打开神圣泉水，确认正文「闪着光的水」和「喝水」选项里的「诅咒」前没有多余空格。
4. 打开大图书馆，确认「阅读」的选牌数量为蓝色，「睡觉」的回复值为绿色。将鼠标停在「打扫」上，确认能看到瓶装火焰、瓶装闪电和瓶装旋风的描述。
5. 打开新一局的地图拼图，完成开场说明后第一次点击左侧从上往下第二个碎块。确认第二块被拿起，白色选中框留在第二块，第一块没有白框。此时用方向键向下移动一次，确认焦点从第二块移到下一块。

游戏内字体、颜色和提示布局以实机画面验收。
