## 布局与状态实现要点

- 编辑保留左池、右图、底部左对白/右并排按钮；归还在池顶。探索隐藏池与整个底部对白/按钮，地图扩展，上沿持续数字与瞬时提示分行。
- 标准池宽300，小屏240；标准按钮宽300，小屏225–240；编辑底区140，720高时112；4K原型按2倍界面显示。精确当前CSS和截图是参考，正式Godot需按可用区域换算，不机械复制CSS像素。
- 地图当前安全区为容器横12%–86%、纵24%–85%。对完整可视内容包围范围（含头像/轮廓）加.6格余量，等比缩放居中。100%是完整放入的上限；没有密集布局开关。正式需按当幕纸纹实际透明边缘复核安全区。
- 持有用整体角色色轮廓、图标透明度和一个头像，放下不保留所有权外观。悬停轮廓在图标下层；四角焦点独立于访问圈。用户已通过持有轮廓和探索焦点。
- 图层：纸→点纹→节点/持有底色→访问/悬停轮廓与图标→焦点/头像→帮助遮罩/帮助面板。避让靠标记排布，不移动领域节点或篡改占地。
- 可前往/已访问/投票消费已有业务状态，不从绘图推导资格。商店仅实际可前往时脉动；Boss访问后停止且无圈，先古完成后不脉动无圈。
- 帮助打开取消持有等语义依REQUIREMENTS；关闭恢复有效焦点。HTML inert与焦点检查不替代Godot输入路由。
- 探索文案依REQUIREMENTS第6节。0提示消失后保留数字0，不加追猎标签；不恢复底部对话。
