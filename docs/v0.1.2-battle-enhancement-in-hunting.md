# 追猎战斗增强方案

本文档适用于 v0.1.2 版本中对玩家持有遗物"建筑师面具"下的战斗增强情况进行详细叙述。以下的更改均必须在"玩家持有建筑师面具"的前提下进行。

## 第一幕

### 密林（Overgrowth）

#### 普通战斗

增加一只《杀戮尖塔》中的怪物[真菌兽（Fungi Beast）](https://sts.huijiwiki.com/wiki/%E7%9C%9F%E8%8F%8C%E5%85%BD)，该怪物的具体属性和意图如下。

生命值：28

初始能力：2层[孢子云（Spore Cloud）](https://sts.huijiwiki.com/wiki/%E5%AD%A2%E5%AD%90%E4%BA%91)

> 注：孢子云是《杀戮尖塔》中的一个敌方buff，效果为"在死亡时给予玩家X回合的易伤。"，其中X为层数。

该怪物的行动如下。

| 行动 | 意图类型 | 效果        |
| ---- | -------- | ----------- |
| 噬咬 | 攻势     | 造成6点伤害 |
| 生长 | 强化     | 获得3点力量 |

意图规律如下。

| 时机               | 行动           | 概率         |
| ------------------ | -------------- | ------------ |
| 战斗开始           | 获得2层孢子云  | /            |
| 第一回合           | 噬咬           | 100%         |
| 连续两次噬咬之后   | 生长           | 100%         |
| 使用生长的下一回合 | 噬咬           | 100%         |
| 非连续两次噬咬之后 | 生长<br />噬咬 | 40%<br />60% |

#### 精英

多尼斯异鸟（byrdonis）

该怪物初始获得6层再生（regen）。

旧日雕像（bygone_effigy）

该怪物原本第1回合会使用沉睡(Sleep)，第2回合才使用苏醒(Wake)。现在改为不会使用沉睡，第1回合就使用苏醒。

异蛙寄生虫（phrog_parasite）

该怪物原本死亡后会召唤4只扭动虫（Wriggler），现在改为召唤5只。1号、3号、5号位的扭动虫固定以“扭动打击”起手；2号与4号位的扭动虫固定以“寄生”起手。

#### boss

墨影幻灵（vantom）

战斗开始时在墨影幻灵的左右两侧各生成一只墨宝（inklet）。

仪式兽（ceremonial_beast）

在其阶段二使用野兽咆哮(Beast Cry)时，不仅给予所有玩家昏眩(Ringing)，还给予所有玩家2层虚弱和脆弱。

同族小队(The Kin)

其中同族神官（Kin_Priest）使用脆弱法球(Orb of Frailty)和虚弱法球(Orb of Weakness)给予的脆弱和虚弱层数由1层变为2层。

### 暗港（Underdocks）

#### 普通战斗

增加一只海洋混混（seapunk）。

#### 精英

花园幽灵鳗（phantasmal_gardener）

每只初始获得的[胆小](https://sts2.huijiwiki.com/wiki/%E8%83%86%E5%B0%8F)层数从6/7层变为9层。

鬼祟珊瑚群（skulking_colony）

初始除了获得20层硬化外壳外，还获得6层覆甲。

骇鳗（terror_eel）

使用恐吓(Terrorize)时，除了给予99层易伤以外，还给予99层虚弱。

#### boss

乐加维林族母（lagavulin_matriarch）

战斗开始时在乐加维林族母的左侧生成一只乐加维林，并使这只乐加维林初始获得爪牙。乐加维林族母的初始生命值减少到原来的50%（不会使其苏醒）。

灵魂异鱼（soul_fysh）

战斗开始时在灵魂异鱼的左侧生成一只蟾蜍蝌蚪，右侧生成一只淤泥旋螺。这两只怪物初始获得爪牙。

瀑布巨兽（waterfall_giant）

在使用即将爆发(About to Blow)时，清除该怪物身上的所有负面状态并获得1层人工制品。

## 第二幕

### 巢穴（Hive）

#### 普通战斗

开始战斗时，所有玩家获得1层虚弱、1层脆弱和1层易伤。

#### 精英

开始战斗时，所有玩家获得2层虚弱。

#### boss

帝皇蟹（Kaiser Crab）

开始战斗时，碾碎爪（Crusher）和火箭（Rocket）获得3层人工制品。

无厌沙虫（the_insatiable）

第一回合改为为自己附加5层[沙坑](https://sts2.huijiwiki.com/wiki/%E6%B2%99%E5%9D%91)并会向抽牌堆和弃牌堆各加入4张[狂乱逃离](https://sts2.huijiwiki.com/wiki/%E7%8B%82%E4%B9%B1%E9%80%83%E7%A6%BB)。

知识恶魔（knowledge_demon）

该怪物的行为之一，知识的诅咒(Curse of Knowledge)，修改如下。

第一次：获得心灵腐化或[劫难](https://sts2.huijiwiki.com/wiki/%E5%8A%AB%E9%9A%BE)；其中卡牌"劫难"应作为知识恶魔战斗中选择效果的选项出现，此后相应效果会作为状态附加在玩家身上。
第二次：获得懒惰或[柔嫩](https://sts2.huijiwiki.com/wiki/%E6%9F%94%E5%AB%A9)；可新增一张名为"柔嫩"的状态牌作为知识恶魔战斗中选择效果的选项出现，该牌的卡面图片将另行提供。此后相应效果会作为状态附加在玩家身上。
第三次：获得衰朽或21点瓦解。

该怪物的其他行为调整如下：

- 抽打(Slap)：改为造成15点（进阶难度9以上改为16点）伤害。
- 知识过载(Knowledge Overwhelming)：改为造成6×3点（进阶难度9以上改为7×3点）伤害。
- 思考(Ponder)：回复量由30改为20。

## 第三幕

### 荣耀（Glory）

#### 普通战斗

增加一只《杀戮尖塔》中的怪物[神秘术士](https://sts.huijiwiki.com/wiki/%E7%A5%9E%E7%A7%98%E6%9C%AF%E5%A3%AB)（Mystic），该怪物的具体属性和意图如下。

生命值：56

初始能力：无

该怪物的行动如下。

| 行动 | 意图类型                                                 | 效果                                                         |
| ---- | -------------------------------------------------------- | ------------------------------------------------------------ |
| 施法 | [策略(状态)](https://sts2.huijiwiki.com/wiki/策略(状态)) | 向玩家的弃牌堆中加入一张"晕眩"或"灼伤"或"虚空"或"毒素"或"呼唤"或"黏液"<br />（每张牌都有相等概率出现，每次只加入一张）。 |
| 治疗 | 强化                                                     | 为随机一名敌人回复12点生命（可以选中自身）                   |
| 增幅 | 强化                                                     | 随机一名敌人获得2点力量（可以选中自身）                      |

该怪物的行动将会以"施法"→"治疗"→"增幅"→"施法"的循环进行。

#### 精英

机甲骑士（mecha_knight）

改为初始获得5层人工制品。

第一回合意图改为"喷火器(Flamethrower)"，不再使用"冲锋(Charge)"。

灵魂枢纽（soul_nexus）

初始获得1层[领地意识](https://sts2.huijiwiki.com/wiki/%E9%A2%86%E5%9C%B0%E6%84%8F%E8%AF%86)。

骑士团伙（knights）

其中连枷骑士（Flail Knight）在使用连枷(Flail)时额外给予所有玩家1层[缠结](https://sts2.huijiwiki.com/wiki/缠结)。

#### Boss

实验体（test_subject）

阶段二开始时不再获得[疼痛戳刺](https://sts2.huijiwiki.com/wiki/疼痛戳刺)，改为获得10层[胆小](https://sts2.huijiwiki.com/wiki/%E8%83%86%E5%B0%8F)和3层[吮吸](https://sts2.huijiwiki.com/wiki/%E5%90%AE%E5%90%B8)。

阶段二的意图"多次爪击(Multi-Claw)"从"造成3+N次伤害，每次10点"（进阶难度9以上为每次11点，N为该行动已使用的次数）改为"造成3+N次伤害，每次9点"（进阶难度9以上为每次10点，N为该行动已使用的次数）。

阶段三开始时依旧自带[天罚](https://sts2.huijiwiki.com/wiki/天罚)。每3回合获得1层细看(Scrutiny)，该回合结束后移除此效果。“细看”的效果为"在你的回合内无法额外抽牌"。

女王（queen）

当火炬头聚合体（TORCH_HEAD_AMALGAM）死亡时，女王会进入第二阶段。在女王第二阶段使用激怒(Enrage)之前，加入一个新的行动，描述如下表，下表中也叙述了"激怒"的改动。

| 行动 | 意图类型 | 效果                                                         |
| ---- | -------- | ------------------------------------------------------------ |
| 重燃 | 召唤     | 在场上召唤2只火炬头，位置均在女王的左侧（当聚合体死亡时，女王会立刻将意图替换为此技能） |
| 激怒 | 强化     | 自身和所有火炬头获得2点力量                                  |

[火炬头](https://sts.huijiwiki.com/wiki/%E6%94%B6%E8%97%8F%E5%AE%B6)是《杀戮尖塔》中的一只爪牙怪物。生命值为50，唯一的行动是攻击造成10点伤害。

永世沙漏（aeonglass）

初始不再获得人工制品，凋萎存在的层数由6层改为12层。

将[凋萎存在](https://sts2.huijiwiki.com/wiki/凋萎存在)的效果更改为"你每打出X张牌，将伤口、灼伤、虚空、晕眩、凋萎各1张加入你的手牌。"，其中X为层数。
