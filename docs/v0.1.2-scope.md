# AllMatters v0.1.2 范围

本文档目前仅为一个记录开发者个人想法的粗糙记录，实际的技术实现仍待确定。

v0.1.2的更新将被称为"拼图更新"（Jigsaw Update），旨在更改《杀戮尖塔2》目前的路线生成逻辑从单方向的树状图变为四个方向均可延展的网状图，基本想法叙述如下。

![fundamental_shape_1](E:\Godot_v4.5.1-stable_mono_win64\sts2mod\AllMatters_docs\references\fundamental_shape_1.jpg)

如图所示，《俄罗斯方块》中有7种不同的形状，而每个形状都由1×1的小方格构成。

而将《杀戮尖塔2》中的每种不一样的节点按一定的限制下随机填充进这7种形状并在形状内相互连接，便能构建出拼图碎块。

目前《杀戮尖塔2》的路线生成均为从先古之民节点出发，按第1/2/3幕分别有15/14/13个节点去生成路线，到每一幕的boss结束。

我希望在本次更新之后，每当玩家进入新的一层时会先停在先古之民节点进行地图的拼图，拼图存在一个类似于商店、宝箱房等独立的UI。在这个UI中会有所有玩家共享的一个拼图碎块池（可以用屏幕左侧的一个竖着的传送带式UI来展示本层可用的拼图碎块），其中包含着若干块由上述规则构建出的拼图碎块；还有一个仅包含当前先古之民节点的拼图"基底"（可以复用现有的地图底图，但变为横向的）。此拼图"基底"应以一个玩家游玩时不可见的网格图为基础（这一点相当重要，方便做拼图时的自动吸附，使节点连线不会歪）。例如，先古之民节点放置在(0, 0)的位置，图标占据3×3网格的大小，而其他节点图标均只占据1×1的大小。每名玩家都允许用鼠标左键单击从拼图碎块池中"拿取"拼图碎块，在"拿取"期间拼图碎块将跟随玩家鼠标移动，并允许单击鼠标右键进行拼图碎块的一次逆时针90度旋转。玩家需要以先古之民节点为起始点开始拼图（同一时刻只能由1名玩家拿着同一块拼图碎块，被拿取的拼图碎块在拼图碎块池UI中以透明度降低显示，已被拼在基底上的碎块将不在拼图碎块池UI中显示），可以在不拿取拼图碎块的前提下使用鼠标右键对不属于同一拼图碎块的两个节点（先古之民节点不属于任一拼图碎块）进行连接以在它们之间产生可通行通路。两个不同拼图碎块之间至多仅能产生两条连接（但先古之民节点允许四个方向均有连接）。

一张来源于[Mysterious Map Mod](https://github.com/mewcodex/MysteriousMap/tree/main)的四方向图如下，可以作为拼图完成后地图样式的参考（但先古之民和boss节点的图标需要有相应的放大，为3×3的大小）。拼图完毕后玩家们的可行动逻辑也可以参考此模组，包括允许从所在节点往周围（上下左右）四格的可到达节点移动（玩家们必须从先古之民节点开始向其他节点移动）、地图会标记进入过的房间、允许玩家重复进入商店等等，当然多人游戏下必须所有玩家选择进入同一节点后才可允许进入。

![mysterious_map_reference](E:\Godot_v4.5.1-stable_mono_win64\sts2mod\AllMatters_docs\references\mysterious_map_reference.png)

拼图环节之前可以引入一段对话式剧情作为教程，告知玩家在拼图后的地图中需要遵循的规则。包括：第1/2/3幕应在15/14/13步之内到达Boss房间，否则游戏将增加难度（以下将步数耗尽后的环节称为“追猎”）。此步数限制可以用以下方式提醒玩家：完成拼图后令每个玩家选择先古之民选项，然后进入与拼图一致的实际地图。在游戏总界面的中上方放置一个小半圆图片，半圆中显示的数字就是玩家剩下的步数。步数会在所有玩家都成功进入某个房间后-1再显示，显示的数字不会低于0 。当玩家步数归零时仍不处于boss房间，触发“追猎”作为惩罚。惩罚的方式包括：玩家进入商店不可与商人交易（可以表现为点击商人后出现的商店UI内是空的，没有任何遗物、卡牌和药水可供付费）、玩家进入休息处只能选择“休息”和“愈合”、玩家进入宝箱房打开的宝箱必定是空的、玩家进入的战斗（包括普通战斗、精英和boss战）将会变得更难（如何更难还可以再商讨）。

当然，如果玩家不想自己手动拼图，也应该在拼图UI中提供一个"令先古之民决定你的去向"按钮，此时由计算机生成一张必定存在至少一条符合条件路线的地图。
