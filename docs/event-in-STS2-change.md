# 二代事件改动一览

以下二代原版事件按第一个会出现的幕数叙述，例如："茶艺大师"在第一幕和第二幕均会出现，则此条目放在第一幕之下。

## 所有阶段

### 滑脚木桥（slippery_bridge）

原"**跨越**"选项改为“**返程**”，文本描述为“你认为恶劣天气下无法再前进，必须折返”，选择此选项会离开此事件。
原"**再撑一会**"选项的文本修改为“坚持向前，有概率随机移除牌组中的一张牌。”
实际效果更改如下：

- 每走一步有`(10%+已选择“再撑一会”的次数×10%)`的概率随机移除牌组中的一张牌。优先从所有可移除的基础牌中选取，**不会选取具有“永恒”词条的卡牌**。一旦玩家随机到了移除卡牌（此时就会执行移除卡牌），则末页为“**放晴**”。“放晴”的文本描述为“在你的坚持下，骤雨与暴风收敛了锋芒，你顺利通过了木桥。”，效果为令玩家离开此事件。
- 包括事件初页一共有3次选择“再撑一会”的机会，即原事件中可选8次缩短为3次（2个中间页）。若第三次选择“再撑一会”仍没有随机到移除卡牌，则末页为“**坠落**”。“坠落”的文本描述为“桥从中间断裂了，你坠入了深谷。”，效果为让**玩家受到13点伤害**，并离开此事件。

### 自助指南（self_help_book）

为三个选项增加可提供的附魔，具体如下。
**”读下封底“**的选项会在以下几个中随机，括号内标出子选项出现的概率：

- 选择一张攻击牌附魔：锋利2。（50%）
- 选择一张攻击牌附魔：活力4。（40%）
- 选择一张攻击牌附魔：墨影。（8%）
- 选择一张攻击牌附魔：本能。（2%）

**”随便读个一段“**的选项会在以下几个中随机，括号内标出子选项出现的概率：

- 选择一张技能牌附魔：灵巧2。（55%）
- 选择一张技能牌附魔：伶俐3。（40%）
- 选择一张技能牌附魔：沉眠精华（slumbering_essence）。（5%）

此选项的描述文本改为如下：

>你随便翻到一页：
>
>“输了可不好玩，所以我从来都不会输。”
>
>你读完了这一段，意外地相当给你启发。你决定在作战时用上其中的一些要点。

**”读完整本书“**的选项会在以下几个中随机，括号内标出子选项出现的概率：

- 选择一张能力牌附魔：迅速2。（40%）
- 选择一张能力牌附魔：稳定。 (45%)
- 选择一张能力牌附魔：蛇行。(13%)
- 选择一张能力牌附魔：涡旋。(2%)

此选项的描述文本改为如下：

>真是本引人入胜的书啊！有几句良言至今深刻在你的脑海之中：
>“获得15点格挡。”
>“跨回合收益。”
>“谁强就削弱谁，所以越强越弱。”
>你的手上沾满了血。

### 药水的未来？（the_future_of_potions）

选项修改为如下所示：

- **放入一瓶药水**：失去*[对应药水]*。获得一次3选1卡牌奖励，候选牌均为升级过的同稀有度、同随机类型的牌。
- **放入一瓶药水**：失去*[对应药水]*。获得一个同稀有度的随机遗物。
- **放入一些金币**：支付50金币，刷新以上选项。

机制描述如下：

- 进入该事件后，药水栏将被冻结，禁止进行饮用和丢弃。前两个选项会从玩家药水栏中不重复地随机抽取一瓶作为待消耗的药水，每个选项选择后会消耗其对应药水。
- 第一个选项只会出现本角色的牌。稀有、事件药水对应稀有卡牌奖励；罕见药水对应罕见卡牌奖励；普通、衍生药水对应普通卡牌奖励。
- 选择"放入一些金币"后将重新随机选取前两个选项中待消耗的药水，优先产生与之前不同的选项。例如，刷新之前第一个选项是消耗攻击药水、第二个选项消耗技能药水；则刷新后应该为第一个选项是消耗技能药水、第二个选项消耗攻击药水。

### 这个还是那个？（this_or_that）

增加一个选项，描述如下。

- **揪出真身**：看看手臂的主人是谁。

选择此选项后，会在以下三种效果中随机抽取一种。

- 无影响（概率为78%）
- 令玩家获得**[恩洛斯的饥饿的脸](https://sts.huijiwiki.com/wiki/%E6%81%A9%E6%B4%9B%E6%96%AF%E7%9A%84%E9%A5%A5%E9%A5%BF%E7%9A%84%E8%84%B8)**（Nloths Mask）。效果为"你打开的下一个非Boss宝箱将是空的。"（概率为20%）
- 令玩家获得**[恩洛斯的礼物](https://sts.huijiwiki.com/wiki/%E6%81%A9%E6%B4%9B%E6%96%AF%E7%9A%84%E7%A4%BC%E7%89%A9)**（Nloth's Gift）。效果为"使你在怪物奖励中遇见稀有牌的几率变为 3 倍。"（概率为2%）

若抽取到第一种情况，事件文本描述为：

>你用尽全力攻向坑洞，一个驼着背、背后长出几条触手的奇怪生物蹦了出来。
>
>它惊恐地看了你一眼，随后头也不回地消失在黑暗之中。

若抽取到第二种情况，事件文本描述为：

>你用尽全力攻向坑洞，一个驼着背、背后长出几条触手的奇怪生物蹦了出来。
>
>它可怜巴巴地拖着脚向后逃去，但你注意到它怀里掉出来一个物件。
>
>当你发现这个物件并不友善时，为时已晚。

若抽取到第三种情况，事件文本描述为：

>你用尽全力攻向坑洞，一个驼着背、背后长出几条触手的奇怪生物蹦了出来。
>
>它可怜巴巴地拖着脚向后逃去，但你注意到它怀里掉出来一个物件。
>
>是一个平平无奇的礼物盒。

**取走蜡烛**：失去14点最大生命值，获得[蓝蜡烛](https://sts.huijiwiki.com/wiki/%E8%93%9D%E8%9C%A1%E7%83%9B)。效果为"战斗中可以打出原本不能被打出的诅咒牌（默认为1费打出；原本有费用的诅咒按原费支付），打出诅咒牌会让你失去 2 点生命并将其消耗。"

若选择了该选项，事件文本描述为：

>你环视了一圈，最后把视线锁定在了一根特别的蜡烛上。
>
>当你用手拿起它时，灼热的火舌吞噬了你的一部分生命。
>
>但你同时也注意到——缠绕在你身上的诅咒松动了。

增加一个选项，仅在玩家有至少一瓶药水时出现此选项。描述如下。

**刺激它**：失去*[对应药水]*，可能获得最大生命值或遗物奖励。

此选项会从玩家药水栏随机抽取一瓶作为待消耗的药水。选择此选项后，会在以下三种效果中随机抽取一种。

- 无影响（概率为57%）

若抽取到第一种情况，事件文本描述为：

>你用药水往头上砸去，在强烈地刺激下，脑蛭一下子弹得远远的。

若抽取到第二种情况，事件文本描述为：

>你用药水往头上砸去，在强烈地刺激下，有关于生机的知识进入你的脑海中。

若抽取到第三种情况，事件文本描述为：

> 你用药水往头上砸去，在强烈地刺激下，有关于方位的知识进入你的脑海中。
>
> 待脑蛭离去后，你顺着这段知识寻找，果然找到了一件物品。

### 传说是真的（the_legends_were_true）

增加一个选项，描述如下。

**耐心寻找出口**：失去12点生命。获得1个随机遗物。

选择此选项会在普通、罕见、稀有遗物中随机给予玩家1个。事件文本描述沿用原有"耐心寻找出口"选项的即可。
