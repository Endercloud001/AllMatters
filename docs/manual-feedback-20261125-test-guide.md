# v0.114.0 与人工反馈验收

## 安装

退出游戏。用测试包对应的 `AllMatters/` 替换游戏 `mods/AllMatters/`，并将完整的 RitsuLib 0.6.16 variant-pack 解压到 `mods/STS2-RitsuLib/`。Beta 包对应 v0.114.0，Public 对照包对应 v0.107.1。Beta 的 RitsuLib 启动日志应显示 `compat branch: 0.114.0`。

## 修复后验证项

1. 开启单人拼图模式，完成当前房间并打开地图。单击合法的下一节点，听节点选中和地图转场音各播放一次。点击空白和当前不可达的节点，确认没有入图音效。
2. 用简体中文进入「茂密的植被」。以 85 点最大生命、41 点当前生命为例，休息说明应以「回复25点生命。」开头，其中只有「25」为绿色。「休息」「锻造」等会触发战斗的选项应将「进入战斗」标为红色。
3. 带「小邮箱」再进入事件。核对回复量、小邮箱药水奖励和红色「进入战斗」在同一行。选休息后，下一页的「进入战斗」按钮文字为红色。
