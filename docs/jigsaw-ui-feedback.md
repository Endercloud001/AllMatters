## 本轮变化

- 新建单人标准跑局默认启用拼图。RitsuLib 主菜单的 Mod 设置 → AllMatters → 拼图模式可保存默认偏好；保留角色页的本次可见入口并放大文字/控件。不会把已有普通跑局改为拼图。
- 按已确认的左侧单列碎块池、右侧地图、底部对白与右侧决策布局接入游戏原生资源，并为顶部原生状态栏留出空间。池与按钮使用原生蓝色框；对白使用羊皮纸配深色文字；地图取当前幕原生上/中/下背景，普通节点、Ancient、点状通路与已访问圈使用原生素材，Boss 使用当前幕原生 Spine 或原生静态节点并保留可前往时的脉动。仅引用游戏资源，不分发提取图片，不合入原型脚手架。
- 仅在已连接控制器且原生当前输入设备为手柄时显示手柄图标。键鼠显示鼠标/滚轮/Esc 提示。
- 探索阶段隐藏碎块池，控制器区域切换跳过隐藏池。
- 原生暂停打开时统一释放拼图输入/快捷键阻挡；原生子菜单全部关闭后再于下一帧恢复，避免吞掉退出确认或把同一次 Esc 再次用于拼图。

## 本批复测步骤

使用与游戏版本匹配的未压缩 AllMatters 目录替换旧测试包。无需重装 RitsuLib；本包不包含 RitsuLib，也不提供 ZIP。保留普通存档，使用专用单人测试局。

1. 主菜单进入 Mod 设置，确认 AllMatters 的拼图偏好默认开启；关闭后开新局确认角色页同步，重新启用。偏好应在退出后保留。
2. 键鼠且无手柄时检查角色页入口、拼图底部均不显示手柄按键。检查羊皮纸、当前幕 Ancient/Boss 与原生房间图标、按钮反馈，以及常用分辨率下对白与决策区的可读性。
3. 手动或自动完成拼图并领取 Ancient 后继续探索：左侧碎块池消失，可前往节点的脉动和访问圈仍生效。
4. 探索时分别通过 Esc 与“暂停”进入原生菜单，检查返回、设置往返、保存退出以及主菜单继续；两条暂停路径应一致，不吞鼠标/确认，不重复打开。
