# AllMatters 发布包体实机验收

从交付 ZIP 选择与你的游戏分支匹配的一份。public 对应 v0.107.1（59260271），public-beta 对应 v0.113.1（d09d48e5）。把解压出的 AllMatters 目录放到游戏的 mods 目录，另在 mods/STS2-RitsuLib 装完整 RitsuLib 0.6.11 variant-pack。public 使用 compat/0.107.1，public-beta 使用 compat/0.113.0。每次换包前退出游戏，两个版本使用同一 Mod ID 和安装目录，逐一替换。

1. 先装后缀为 `-lossless.zip` 的无损包。在老乞丐事件付费，观察预加载的牧师插画能否立即出现。再进斗兽场确认插画正常，并查看心灵绽放。用常用分辨率和可用的最高分辨率分别保存这三个场景的截图。
2. 换同一游戏分支后缀为 `-lossy.zip` 的有损候选。用相同显示设置复现。查看斗兽场的细线、心灵绽放的渐变，以及老乞丐切换牧师插画时的透明边缘。分别与无损版同分辨率的截图对照。
3. 记录游戏分支、分辨率和异常位置。有损观感通过后再采用有损包。切回无损时，替换为同一游戏分支的 `-lossless.zip`。

自动验证通过隔离的 Godot 项目检查十张纹理的加载和尺寸。游戏启动和两种压缩模式的视觉差异由实机验收确认。
