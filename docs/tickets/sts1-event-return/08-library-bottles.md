## What to build

在已有图书馆中补齐打扫，玩家获得可用瓶子并绑定一张牌；升级、战斗内变化及下一场战斗均保持正确规则。

本票按父规格 A21, A22, A23, A24, A29 验收。

## Acceptance criteria

- [ ] 仅从尚未持有且有合法目标的瓶子种类中等概率抽取；无可用种类禁用打扫。火焰/闪电/旋风分别匹配攻击/技能/能力。
- [ ] 目标没有固有且未被其他瓶子绑定；获得后必须选一张、不可取消，牌组实际获得瓶子赋予的固有。
- [ ] 升级保留绑定；持有遗物时战斗外不可移除或变化，战斗中允许消耗/变化且产物不继承绑定。
- [ ] 永久原牌绑定不因战斗内消耗/变化而解除，下一场仍由原牌固有；同名其他牌不能被误绑定，读档保持正确身份。
- [ ] 失去瓶子只解除其关联和其赋予的固有，不移除独立来源的固有。
- [ ] 三瓶只由图书馆打扫提供，不进入常规、商店及其他事件通用遗物池；补齐后回归阅读、睡觉和转盘候选排除。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
