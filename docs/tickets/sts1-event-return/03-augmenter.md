## What to build

玩家在增益研究者处完整选择默认固有的 J.A.X.、变化升级两张牌，或交出初始遗物换取第三回合衰退的突变之力。

本票按父规格 A01, A08, A09, A10 验收。

## Acceptance criteria

- [ ] 仅 Act 2 且全员至少两张可移除牌时准入，三个分支实际执行并结束，不带入上游无关模式。
- [ ] J.A.X. 为 0 费技能，默认固有，失去 3 生命、加 2 力量，升级加 3 力量；未升级实例确实固有。
- [ ] 变化两张合法牌后升级变化得到的新牌；不升级被替换旧牌或修改共享模板。
- [ ] 按五名原版角色的初始遗物定义识别并交出实际原件；已失去或被替换时禁用突变剂，不以遗物栏第一件代替、不免费领取。
- [ ] 突变之力每场战斗开头加 3 力量；前两拥有者回合结束不扣，第三回合结束一次扣 3；他人回合不推进，下一场重新计时。
- [ ] 保留 Balance 衰退 Debuff 与人工制品等未修改交互；验证多回合、第二场战斗和多人拥有者时点。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
