## What to build

玩家实际旋转转盘，并按同一已确定结果看到和领取六类奖励或代价；无目标/空遗物池不会造成重抽或卡住。

本票按父规格 A15, A16, A17, A29 验收。

## Acceptance criteria

- [ ] 六种结果各 1/6，动画和结算使用同一结果；金币随幕为 100/200/300，其他为随机遗物、回复全部生命、霉运、删一张牌、固定失去 7 生命。
- [ ] 遗物先以普通/罕见各 50% 选档再抽合法候选；仅一类为空改用另一类，两类皆空说明后结束，不重抽/补偿，不扩大稀有度。
- [ ] 抽中删牌但无合法牌时先显示结果、再说明无目标、最后结束，不重抽、不补偿。
- [ ] 瓶装遗物不得进入通用随机候选；本票不依赖瓶装实现完成才可验证正常候选规则。
- [ ] 游戏支持的保存节点恢复保留已确定结果及结算状态，不重复发奖、加诅咒、扣生命或删牌。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
