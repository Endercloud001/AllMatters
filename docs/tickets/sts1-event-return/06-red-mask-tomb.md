- [ ] 已持有红面具者能领取 222 金币，离开无改变；未修改选项逻辑及原生遗物约束继承 Balance。
- [ ] 使用原生红面具，不重新注册同名遗物，也不修改其常规稀有度或遗物池。
- [ ] 验证 149/150 金币、全队仅一人持面具以及实际可保存节点恢复后不重复奖励。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
