## What to build

玩家能独立完成书本阅读与风险选择，活着支付拿书代价后主动选一本，并在后续战斗使用该书完整效果。

本票按父规格 A04, A05, A06, A07, A29 验收。

## Acceptance criteria

- [ ] 仅 Act 2 且全队无人持有三书任一本时出现；每名玩家独立阅读、停止、离开和选书，可与队友选同一本。
- [ ] 初页阅读不扣血且可离开；三个中间页只有继续并依次失去 1、2、3 生命；末页拿走额外 15、停止额外 3，所有进阶相同，名义累计分别 21/9。
- [ ] 允许致死选项并显示提示，正常执行伤害、防死亡及复活；结算后仍存活才继续，确认死亡结束自己的事件、不发书，不打断存活队友。
- [ ] 拿书改为死灵之书、尼利宝典、英雄宝典三选一且仅领取一本；不是随机书或重复领取。
- [ ] 三书及必要死灵诅咒/能力可用：死灵书每回合首次符合费用至少 2 的攻击额外打出并附死灵诅咒；尼利候选升级；英雄宝典首回合本职业能力牌本回合免费；其他语义继承 Balance。
- [ ] 覆盖各阅读页、领奖前后游戏支持的保存节点，以及书籍效果的后续回合/战斗；不重扣生命、不重复发书/诅咒。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
