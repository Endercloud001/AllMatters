## Parent

## What to build

全队能共同选择各自交出全部金币，或进入三人帮战斗并各领取一次红面具及继承奖励。

本票按父规格 A01, A25, A29, A31 验收。

## Acceptance criteria

- [ ] Act 2、累计层数至少 23、全队无人持有红面具；覆盖 22/23 层及队伍仅一人持面具的准入差异。
- [ ] 统一交钱时每人失去各自全部金币，不是只扣发起者或重复遍历扣款；未修改叙事/离开流程继承 Balance。
- [ ] 开战使用完整 Pointy/Romeo/Bear 及资源；Bear 首回合熊抱施加 -2 敏捷，图鉴归类为事件战斗。
- [ ] 胜利每位参战者各获得原生红面具及未修改的 Balance 显式 25–35 金币等奖励，不能叠加重复的默认奖励或重复给全队。
- [ ] 正确处理两分支实际事件战斗进入、结束与离开；本票不要求其他事件先建通用战斗框架。
- [ ] 完成 beta 真实战斗和主客机分支结算检查，覆盖可保存节点；记录回放验证结果或具体未验证边界。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
