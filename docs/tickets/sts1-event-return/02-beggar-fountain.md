## What to build

玩家可用 75 金币从老乞丐处删除一张牌，或通过神圣泉水清除全部可移除诅咒；两个小事件各自完整可玩。

本票按父规格 A01, A02, A11, A29 验收。

## Acceptance criteria

- [ ] 老乞丐只在全员至少 75 金币时出现；给钱正确扣 75 并删一张合法牌，离开无改变，无牌可删则禁用给钱而不改变准入。
- [ ] 泉水只在每名玩家均有可移除诅咒时出现；喝水移除该玩家全部可移除诅咒，保留永久诅咒、死灵诅咒及其他牌，不增加伤害或其他模式分支。
- [ ] 这是个人选项：各玩家各自选择和结算，不因队友点击改变自己的牌组/金币。
- [ ] 覆盖已付款待删牌及清除前后的实际可保存节点；恢复不重扣金币、不重复移除、不跳过玩家尚需完成的选择。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
