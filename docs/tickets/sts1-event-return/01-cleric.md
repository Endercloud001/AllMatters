## What to build

玩家能在正式加载的 AllMatters 中遇到牧师，选择治疗、净化或离开；以这个完整玩法贯通必要依赖、资源、测试入口和开发安装包。

本票按父规格 A01, A03, A32 验收。

## Acceptance criteria

- [ ] 全员至少 35 金币时允许事件出现；治疗扣 35、名义回复最大生命的 25% 并向下取整；净化扣 75 并移除一张合法牌；一次服务后结束，离开不改变资源。
- [ ] 金币 34/35、74/75 及无可移除牌时，准入与选项资格分别正确；无法执行的主动选项禁用且不扣费，不提高原有准入条件。
- [ ] RitsuLib 0.6.7 对应分支模块、事件模型注册、中英文、事件图片及必要 Godot/PCK 导出实际接通；产物与 manifest、依赖及安装说明一致，不能只交付空框架。
- [ ] 补足基于真实事件进入/选项执行及可观察结果的测试驱动；复用既有 Godot 宿主并说明生命周期替代范围，不为每事件另造框架。
- [ ] beta 实际加载、显示、选牌及服务结束可复现，public 通过对应真实 DLL 构建与可运行的行为检查；public 完整加载留待环境及集成票验证。
- [ ] 首次复制上游代码/素材前完成对应来源、许可、归属及项目整体许可证处理；只纳入本票需要的内容，保留现有你好世界回归。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
