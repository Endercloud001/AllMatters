## What to build

第三幕玩家可完整选择双乐加维林凯旋、升级全牌与绽放印记、富有或无伤痛，并获得对应各自效果。

本票按父规格 A12, A13, A14, A28, A29, A31 验收。

## Acceptance criteria

- [ ] 按 Balance 共享选择结算，每人费用和效果各一次；37 层前富有、38 层起无伤痛，单双人统一且互斥。
- [ ] 富有加 999 金币、凡庸与贪婪各一张；无伤痛回满生命、执迷与悔恨各一张，执迷必须使用 Enthralled。
- [ ] 觉醒升级所有可升级牌并获得绽放印记；印记阻止持有者的战斗、休息及事件治疗，不影响其他玩家。
- [ ] 凯旋仅一场两只一代乐加维林，默认睡眠及进阶语义继承 Balance；两只各自计时/受伤唤醒，使用原生多人缩放，不替换成族长或接上游第二战。
- [ ] 胜利每名参战者获得 100 金币、随机稀有遗物和正常 Boss 卡牌规则的一份本职业稀有三选一；可跳过，保留解锁、人数、升级及奖励修改钩子，无默认战利品重复。
- [ ] 房间仍为事件流程，不伪装 Boss 或正常过幕；验证两版进入/结束/恢复差异和 beta 真实共享战斗、奖励及可保存节点。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
