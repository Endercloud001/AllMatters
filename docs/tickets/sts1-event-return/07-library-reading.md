## What to build

玩家在第二幕图书馆从其他四个原版角色的合法候选中选一张牌，或选择睡觉治疗；打扫由后续瓶装票补齐。

本票按父规格 A19, A20, A29 验收。

## Acceptance criteria

- [ ] 事件只在 Act 2 出现；阅读和睡觉是个人选项，睡觉名义回复 33% 最大生命并按 Balance 向下取整。
- [ ] 只合并其他四个原版角色已解锁、符合当前人数限制的合法奖励牌；排除当前角色、无色、诅咒、事件专属与其他 Mod 角色牌。
- [ ] 合池逐张牌随机、不放回，最多 20 张互不重复；不先按角色抽样、不用重复牌凑数，保留未修改的升级等生成语义。
- [ ] 有 1–19 张候选展示全部并选一张，零候选禁用阅读；单人不出现多人专用牌。
- [ ] 选中牌仅加入一次，保存恢复不重抽候选或重复加牌；中英文选牌界面正确。
- [ ] 本票暂不提供打扫分支，不放置领取后无目标的假实现；后续第 8 票补齐整场事件。这是交付边界，不是修改最终规格。
- [ ] 遵循父规格及范围事件表；未修改行为继承 Balance，不重新访谈 Q1–Q20，不引入表外功能、额外 hash/冻结 contract/baseline/gate。
- [ ] 除环境/集成票的专门边界外，本票包含相应中英文、图片/场景/PCK、模型行为、真实目标双分支构建及 beta 实际可玩验证；普通测试只针对具体失败风险，公开行为入口优先。
- [ ] 本票引入的代码/素材先核对许可与归属；记录实际命令、版本、结果和宿主替代边界。真实联机/回放/完整 public 未执行时如实列出，不能以无界面通过替代实机证据。
