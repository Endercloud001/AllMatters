## 打开与权限

键盘焦点不在其他文本输入框时，按反引号键（通常位于数字 1 左侧）切换原生控制台，输入命令后回车执行；Esc 关闭。两版原生 `NDevConsole._Input` 也识别单引号、星号、脱字符及 Shift+8，具体键位受键盘布局影响。

命令继承原生 `AbstractConsoleCmd.DebugOnly`。原生允许调试命令的条件为编辑器、测试模式、已加载 Mod，或原设置 `FullConsole`；本实现不绕过这些条件，也不修改用户配置以启用控制台。保留原有 Mod 标记、成就、解锁及排行榜限制，不把测试命令加入正式 HUD。

上述打开方式和启用条件来自两版真实 DLL 方法体核实，尚不等于已在真实游戏设备上验证按键。

## 命令与使用阶段

|命令|参数|允许阶段与身份|实际作用|
|---|---|---|---|
|`am_jigsaw_reset`|无|Host；显示且接收输入的可编辑拼图，原生当前房为 MapRoom，未暂停|经原生顺序动作归还全部碎块、持有预览与连线，保留本幕原池；重复执行无害。授权检查后的阶段拒绝。|
|`am_steps N`|仅一个十进制整数，0–2147483647|Host；稳定非战斗探索，当前房栈一层，无待进入、缺席 Ancient 补领或暂停|只设置本幕剩余额度；不伪造已走步数或首次进度，不解除已经激活的追猎，沿下一正常完整保存点保存。|

两条命令都先本地校验 Host 身份，再提交原生顺序队列；提交成功提示与最终执行/保存完成是两个时刻。Client 不能用命令代替 Host 操作。

## 示例与预期

|输入/场景|预期|
|---|---|
|编辑时放置碎块、连线并持有另一碎块后输入 `am_jigsaw_reset`|提示已提交 Host 重置请求；队列接受后全部归还、本幕原池不变，保存成功后记完成日志。|
|`am_jigsaw_reset extra`|拒绝并提示无参数用法；不改变布局。|
|Client 输入任一命令|拒绝并提示只有 Host 可以执行；共享状态不变。|
|稳定探索时输入 `am_steps 40`|等待原生顺序接受后剩余额度为 40；已走步数、首次进度、当前根房安全状态不改。|
|`am_steps 0`|当前未完成的安全根房不会在命令当刻发面具；完成后按原完成边界结算。若已完成房间、正等下一目的地，命令当刻也不发面具，但下一房立即受罚，包括首次 Boss。|
|追猎已激活后输入 `am_steps 99`|额度变为 99，追猎继续，不能借命令解除。|
|`am_steps`、`am_steps -1`、`am_steps 1.5`、`am_steps x`、`am_steps 2147483648`、`am_steps 1 2`|原子拒绝；额度、进度、房间、历史不变。|
|战斗、进入处理中或其他非法阶段使用命令|拒绝；不生成战中混合保存点。|
